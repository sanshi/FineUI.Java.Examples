下面用一个可点击按钮的页面说明：在新的 Spring Boot 项目中，怎样接入 FineUI.Java。完成后访问 /hello，点击按钮会触发 Java 服务端事件。

1. 引入依赖

先用 Spring Initializr 或 IDE 创建一个 Java 17+ 的 Spring Boot 项目，再在 pom.xml 的 <dependencies> 中加入 FineUI.Java。

XML
<dependency>
    <groupId>com.fineui</groupId>
    <artifactId>fineui-java</artifactId>
    <version>16.0</version>
</dependency>

版本号按实际取得的 FineUI.Java 制品填写。引入后无需编写 @Configuration：FineUI.Java 会自动注册 f: 标签方言、页面路由、回发入口，以及内嵌的 F.js/CSS 资源。

2. 建立三个文件

假设启动类位于 com.example.demo。页面类必须放在它的子包中，才能被自动扫描。

目录结构
src/main/java/com/example/demo/
├── DemoApplication.java
└── pages/HelloPage.java

src/main/resources/templates/
├── shared/layout.html
└── hello.html

3. 母版与第一个页面

母版只需放一次 f:styles 和 f:scripts；所有页面共用它。

HTML
<!-- templates/shared/layout.html -->
<!DOCTYPE html>
<html xmlns:f="http://fineui.com/java">
<head>
    <meta charset="UTF-8" />
    <f:styles></f:styles>
</head>
<body>
    <th:block layout:fragment="body"></th:block>
    <f:scripts></f:scripts>
</body>
</html>
Java
// src/main/java/com/example/demo/pages/HelloPage.java
package com.example.demo.pages;

import com.fineui.java.core.EventArgs;
import com.fineui.java.core.FineUIPage;
import com.fineui.java.core.FineUIPageBase;

@FineUIPage("hello")
public class HelloPage extends FineUIPageBase {

    public void btnHello_Click(Object sender, EventArgs e) {
        showNotify("你好，FineUI.Java！");
    }
}
HTML
<!-- templates/hello.html：路由 hello 与模板路径同名 -->
<!DOCTYPE html>
<html xmlns:f="http://fineui.com/java" layout:decorate="~{shared/layout}">
<head>
    <title>第一个 FineUI.Java 页面</title>
</head>
<body>
    <th:block layout:fragment="body">
        <f:button id="btnHello" text="点击问好"
            on-click="btnHello_Click"></f:button>
    </th:block>
</body>
</html>

@FineUIPage("hello") 同时确定 URL 和模板：访问 /hello 时，FineUI.Java 使用 templates/hello.html。按钮的 on-click 指向页面类中的同名方法；点击时通过 AJAX 回发，不会整页刷新。

4. 配置并启动

application.properties 可以为空。开发时建议关闭模板缓存；主题等全局选项按需再加。

Properties
# src/main/resources/application.properties
spring.thymeleaf.cache=false
fineui.theme=pure_black
Shell
./mvnw spring-boot:run

浏览器打开 http://localhost:8080/hello。能看到按钮并在点击后弹出“你好，FineUI.Java！”，即表示接入完成。

常见遗漏：页面类不在启动类包的子包中会扫描不到；路由和模板路径不一致会找不到页面；母版缺少 f:styles 或 f:scripts 时，控件无法正常呈现或回发。
